# Portafolio

Proyecto de Next.js con TypeScript.

## Desarrollo local

Con Node.js 22 o posterior, ejecuta estos comandos en la carpeta del proyecto.

```powershell
npm.cmd ci
npm.cmd run dev
```

Abre [http://localhost:3000](http://localhost:3000). La página principal está en `app/page.tsx`.

## GitHub Pages

`npm.cmd run build` genera el sitio estático en `out/`. GitHub Actions publica los cambios de `main`.
